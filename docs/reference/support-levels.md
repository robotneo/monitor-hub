# Support levels

Every component and stack declares one repository support level.

- `experimental`: contract or prototype only; destructive use is not recommended.
- `preview`: implemented and validated in the documented scope, but compatibility
  or upgrade guarantees may still change.
- `supported`: maintained, documented and covered by its declared validation and
  smoke-test matrix.

A deployment mode is only listed after its implementation exists. A component's
overall level does not make unlisted modes supported.
